## Drips — ERC-20, on-chain, no account

[Drips](https://www.drips.network) is a permissionless, non-custodial protocol for funding open-source work: anyone, from anywhere, can send ERC-20 tokens to a project, the funds accrue to its GitHub repository, and the maintainer collects them. No account, no KYC, no fee to the giver.

Fund ownerwatch here: **https://www.drips.network/app/projects/github/imal1ice/ownerwatch**

Drips is experimental software provided as-is; send only what you are comfortable sending.
